# Five-second test: five heroes (A/B pre-test)

For 5 developers who haven't seen deeper. Same method as brand/lineup/README.md.

1. Show one tile (`tile-F` … `tile-K`, phone `-375` or desktop `-1440`, same for everyone) for five seconds, then hide it.
2. Ask: "What is this, and who is it for?" and "What would you do next on this page?" Write both answers down word for word.
3. All five tiles, in a different order per person.
4. Open `key.json` only after every answer is written down.

Score per tile: a pass if the person says roughly "a skill or plugin for AI coding agents that improves or expands your prompts or requests". Note separately if they name the install or copy action as their next step.

Pass: a tile passes at 3 of 5 people or more. The two tiles with the most passes (ties broken by "named the install action") go to the live test. If fewer than two pass, nothing goes live: revise and retest.
