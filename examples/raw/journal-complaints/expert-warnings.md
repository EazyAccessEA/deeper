# What experts warn users about

Written 13 November 2026, before any review was coded. Every source was opened on that day. Each warning is mapped to the complaint code that would hold it, and to the praise code where a happy user might be describing the same thing from the other side.

| # | Warning | Complaint code | Praise code | Source |
|---|---|---|---|---|
| W1 | Sycophancy: the assistant tells you what you want to hear | C8 | P4 | OpenAI, "Sycophancy in GPT-4o", 29 April 2025, https://openai.com/index/sycophancy-in-gpt-4o/ ; OpenAI, "Expanding on what we missed with sycophancy", 2 May 2025, https://openai.com/index/expanding-on-sycophancy/ ; Sharma et al., "Towards Understanding Sycophancy in Language Models", arXiv:2310.13548 |
| W2 | Made-up facts and citations | C3 | P6 | Walters and Wilder, Scientific Reports, 2023, https://www.nature.com/articles/s41598-023-41032-5 (55% of GPT-3.5 and 18% of GPT-4 citations fabricated); Kalai et al., "Why Language Models Hallucinate", arXiv:2509.04664 |
| W3 | Over-reliance: trusting it so much you stop checking | C3 | P6 | Lee et al., CHI 2025, https://doi.org/10.1145/3706598.3713778 (319 workers: more confidence in AI went with less critical thinking) |
| W4 | Emotional dependence | none | P3 | OpenAI and MIT Media Lab, affective use study, 21 March 2025, https://openai.com/index/affective-use-study/ ; Fang et al., arXiv:2503.17473 (981 people, 4 weeks: heavier use went with more loneliness and dependence) |
| W5 | Privacy: chats used for training, kept, read by reviewers | C9 | none | King et al., arXiv:2509.05382 (all 6 US frontier developers appear to train on chats by default); Anthropic consumer terms update, https://www.anthropic.com/news/updates-to-our-consumer-terms ; Gemini Apps Privacy Hub, https://support.google.com/gemini/answer/13594961 |
| W6 | Relying on it for health decisions | C3 | P5 | Bean et al., arXiv:2504.18919 (1,298 people: models alone named the condition 94.9% of the time, people using them under 34.5%) |

W3 and W6 share code C3 with W2 on the complaint side, because a user complaining about either would be complaining that an answer was wrong. On the praise side they get their own codes.

A warning is "quiet" (README, pass marks) if its complaint code holds under 5% of complaints. W4 has no complaint code: nobody leaves one star because the app is too good a friend, so its test is the praise side only.
